# 주간 운영 사이클 (SOP)

> **갱신일:** 2026-05-03

InitialTrading의 한 주는 **금요일 마감 → 다음 금요일 마감** 으로 끊어진다.
의사결정의 단위는 "주(week)" 이며, 월~목 사이에 새로운 종목을 즉흥적으로 진입하지 않는다.

---

## 사이클 한눈에 보기

```
금 15:30 마감
   │
   ├─ ① 데이터 업데이트 + 퀀트 분석 (자동, 5분)
   │     2_weekly.bat 더블클릭 → run_pipeline.py 실행
   │
   ├─ ② 텔레그램으로 시장요약 + TOP5 + HTML 수신
   │
   └─ 금 저녁 — Claude 세션 (15분)
         │
         └─ /friday-review 실행 → 시장+포트+TOP5 통합 → 차주 액션 플랜 합의
              └─ trading_journal.md 업데이트 + 월요일 주문 메모 확정

토 ~ 일 — 자유 (의문 사항 추가 검토)

월 09:00 — 시초가 부근 주문 실행 (Carlos 직접)
   │
   └─ 월 저녁 — Claude 세션 (5분) — 체결 결과 기록

화 ~ 목 — 보유 종목 모니터링 (손절/목표가 알림)

다시 금 15:30 마감 → 사이클 반복
```

---

## ① 금요일 — 분석 & 전략 (필수)

### 자동 단계 (5분, PC 작업)

1. PC 부팅 후 `D:\WorkSpace\InitialTrading\2_weekly.bat` 더블클릭.
2. `run_pipeline.py` 가 다음을 자동 수행:
   - `update_data.py` — FinanceDataReader → MongoDB 증분 업데이트
   - `weekly_analysis.py` — 4팩터 스코어링 → TOP5 산출
   - `generate_report.py` + `build_html.py` — HTML 리포트 생성
   - `send_telegram.py` — 봇으로 요약 + HTML 전송
3. 텔레그램 메시지 수신 확인.

> 실패 시: MongoDB 미실행 가능성 → Docker 컨테이너 기동 후 재시도.

### Claude 세션 (15분)

Cowork에서 `/friday-review` 또는 "금요복기" 입력.
스킬이 자동으로:

1. **시장 요약** — KOSPI/KOSDAQ 주간 수익률, 상승/하락 종목수
2. **포트폴리오 점검** — 보유 종목 주간 등락, 손절/목표가 근접 여부
3. **TOP5 분석** — 4팩터 점수, 매수/손절/목표가, 선정 이유
4. **차주 액션 플랜 초안** — 신규 진입 후보 / 보유 유지 / 청산 후보

Carlos는 위 4단계 결과를 보고:

- ✅ 진입할 신규 종목 1~2개 선택 (또는 패스)
- ✅ 청산할 보유 종목이 있으면 결정
- ✅ 추가 매수 종목이 있으면 결정
- 📝 위 결정을 `trading_journal.md` 의 "이번 주 액션 플랜" 항목에 기록

---

## ② 월요일 — 주문 실행 (필수)

### 09:00 직전

- 미래에셋 M-Stock 앱 실행
- 금요일 합의한 종목/수량/가격 확인
- **시초가 ±1% 지정가** 또는 **시장가** 선택

### 주문 후

- 체결 가격/수량 캡처
- Cowork에서 짧게 보고: "체결: SPY 5주 @ 580원" 같은 한 줄
- Claude가 `trading_journal.md` 의 "체결 결과" 칸 자동 업데이트

---

## ③ 화 ~ 목 — 모니터링 (선택)

### 일일 체크 (Carlos)

- 보유 종목 주가, 손절/목표가 근접 여부 확인
- 손절가 이탈 → **즉시 청산** (다음 세션까지 기다리지 않는다)

### Claude 세션 (필요 시)

- 트리거 메시지: "오늘 [종목명] 어땠어?", "이거 손절 칠까?"
- 스킬: `portfolio-checkup`
- 출력: 보유 종목 현재가/손익, 매매 시그널 yes/no
