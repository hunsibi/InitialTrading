# /분析 — 주간 퀀트 분析 파이프라인

D:\WorkSpace\InitialTrading 의 주간 분析 파이프라인을 실행하고 결과를 보여주는 커맨드.

파이프라인 순서: 데이터 업데이트 → 글로벌 기관 포트폴리오 수집 → 퀀트 분析(4모델) → 리포트 생성(한미 시총 포함) → HTML 빌드 → 텔레그램 전송

---

## 1단계: 시작 안내

사용자에게 먼저 출력한다:
> 분析을 시작합니다... (약 3~5분 소요)
> 데이터 업데이트 → 기관 포트폴리오 수집 → 퀀트 분析(4모델) → 리포트 생성 → HTML 빌드 → 텔레그램 전송 순으로 진행됩니다.

## 2단계: 파이프라인 실행

```bash
cd D:/WorkSpace/InitialTrading && python run_pipeline.py 2>&1
```

**출력 결과 판단:**

- `완료! 텔레그램을 확인하세요` 포함 → **성공** → `pipeline_ok = True` 기록 후 3단계로
- `MongoDB에 연결할 수 없습니다` 포함 → **MongoDB 미실행**:
  > ⚠️ MongoDB 서비스가 실행 중이지 않습니다.
  > 파이프라인을 실행하려면 PC에서 `2_weekly.bat`를 실행해주세요.
  > 아래는 가장 최근에 저장된 분析 데이터입니다.

  → 3단계(기존 데이터 fallback)로
- 그 외 오류 → 오류 내용 간략 보고 후 3단계로

## 3단계: 데이터 파싱

```bash
cd D:/WorkSpace/InitialTrading && python parse_report.py 2>&1
```

출력 첫 줄이 `NO_DATA` 이면: "아직 분析 데이터가 없습니다. PC에서 `2_weekly.bat`를 먼저 실행해주세요." 안내 후 종료.

파싱 출력 형식:
```
DAYS_OLD=N
DATE=YYYY-MM-DD
KS=수익률%|상승수|하락수
KD=수익률%|상승수|하락수
US_SP=수익률%|상승수|하락수     (S&P 500 컴포넌트 기준, 빈 값이면 생략)
US_NQ=수익률%                   (NASDAQ Composite 지수, 빈 값이면 생략)
US_DJ=수익률%|상승수|하락수     (Dow Jones 30 종목 기준, 빈 값이면 생략)
S0=종목명|코드|시장|업종|현재가|주간수익률|12주수익률|RSI|거래량배수|매수가|손절가|손절%|목표①|목표①%|목표②|목표②%|이유1;;이유2;;이유3
S1=... S2=... S3=... S4=...   (안정 대장주 모델 TOP5)
M0=종목명|코드|시장|업종|현재가|주간수익률|12주수익률|RSI|거래량배수|매수가|손절가|손절%|목표①|목표①%|목표②|목표②%|이유1;;이유2;;이유3
M1=... M2=... M3=... M4=...   (단기 모멘텀 모델 TOP5)
E0=ETF명|코드|시장|테마|현재가|주간수익률|12주수익률|RSI|거래량배수|매수가|손절가|손절%|목표①|목표①%|목표②|목표②%|이유1;;이유2;;이유3
E1=... E2=... E3=... E4=...   (ETF 추천 모델 TOP5, ETF 모델 실패 시 빈 값)
INST_COUNT=N
INST0=기관명|공시날짜|기준분기|섹터1:비중|섹터2:비중|섹터3:비중|TOP종목1|TOP종목2|TOP종목3|총보유수
INST1=... ... INST10=...      (글로벌 기관 포트폴리오, 최대 11개)
I0=종목명|코드|시장|업종|현재가|주간수익률|12주수익률|RSI|거래량배수|매수가|손절가|손절%|목표①|목표①%|목표②|목표②%|이유1;;이유2;;이유3
I1=... I2=... I3=... I4=...   (기관연동 한국 종목 TOP5, 없으면 빈 값)
KR_CAP0=종목명|코드|시총(조원)|현재가|주간수익률
KR_CAP1=... ... KR_CAP4=...   (한국 시총 TOP5)
US_CAP0=종목명|티커|시총($B)|현재가|주간수익률
US_CAP1=... ... US_CAP4=...   (미국 시총 TOP5)
```

DAYS_OLD ≥ 7 이고 파이프라인도 실패했다면, 결과 상단에:
> ⚠️ [N]일 전 데이터입니다.
