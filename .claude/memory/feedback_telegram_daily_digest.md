2026-08-29, 사용자가 매일 장마감 후 오는 텔레그램 메시지(TOP5 추천, 성과리포트, 기관동향 등 7개 메시지)를
"스팸 느낌"이라며 아래 3가지만 남기고 전부 삭제하도록 요청함:
1. 코스피/코스닥/나스닥/S&P500/필라델피아반도체(SOX) 지수
2. 보유 종목 현재가·등락률
3. 삼성전자·SK하이닉스 외국인/기관/개인 매매 동향

이에 따라 `send_telegram.py`를 전면 재작성 — 기존 TOP5 추천/성과리포트/HTML파일/기관동향 메시지를 모두 제거하고
위 3가지만 담은 메시지 1건만 전송하도록 변경함. 상세 구현은 [[project_telegram_digest_rewrite]] 참고.

**Why:** 정보량이 많아 실제로는 읽지 않게 되어 오히려 역효과. 사용자가 명시적으로 "다른 것 다 지우고" 이 3개만
남기라고 요청 — 절충안 없이 정확히 이 범위로 유지할 것.

**How to apply:** 앞으로 텔레그램 발송 내용에 새 항목을 추가해 달라는 요청이 없는 한, `send_telegram.py`에
TOP5 추천·성과·기관 데이터 등을 다시 끼워넣지 말 것. TOP5 추천/성과추적/기관동향 정보 자체는 계속 필요하면
HTML 리포트(`outputs/reports/report_*.html`)나 GitHub Issue 쪽에서 확인하도록 안내.
