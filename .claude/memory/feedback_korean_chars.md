코드, 주석, 마크다운 문서에서 분석의 '석' 자리에 한자(유니코드 U+6790)를 절대 사용하지 말 것.
반드시 순수 한글 `분석`으로만 작성해야 한다.

**Why:** 터미널/UI에서 한자가 깨져 보이는 문제 발생. 사용자가 직접 수정 요청함.

**How to apply:** 항상 `분석`(한글)으로 작성. 잔존 여부 확인은 Grep 툴로 패턴 U+6790 검색.
